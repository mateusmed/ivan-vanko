Sobre o Sistema

Este sistema, conhecido como Ivan-Vanko, é uma plataforma para a criação e visualização de dashboards interativos. Ele permite que os usuários montem layouts de grade personalizados, salvem e carreguem configurações de dashboard e visualizem dados de forma dinâmica.

A arquitetura é baseada em serviços, permitindo a fácil integração de novas fontes de dados e tipos de gráficos.
